# Personal Mini-Toolkit — Week 8 Final Project

## Project Description

The Personal Mini-Toolkit is a Python program that combines three useful tools in one menu-driven application.

## Tools Included

1. **Simple Calculator:** Performs addition, subtraction, multiplication and division.
2. **To-Do List:** Allows users to add, view and remove tasks.
3. **Number Guessing Game:** Challenges users to guess a randomly selected number between 1 and 10.

## Python Concepts Used

- Variables and data types
- User input and output
- If, elif and else statements
- While and for loops
- Lists and list methods
- Functions
- F-strings
- Exception handling

## Project Files

- `toolkit.py` — Main Python program.
- `toolkit_plan.txt` — Project planning document.
- `screenshots/` — Screenshots showing the program and its tools.

## How to Run the Program

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
py toolkit.py
```

5. Select a tool from the main menu.
6. Choose option 4 to exit.

## Project Reflection

The hardest part of this project was building the menu loop and making sure each tool returned to the main menu correctly. The most challenging bug was handling user choices and ensuring that invalid inputs did not crash the program. I learned how to use lists to store and manage tasks while the program runs. I also improved my understanding of loops, conditionals, functions and user input. Testing each tool helped me identify mistakes and improve the program. If I had one more week, I would add more tools and improve the design of the menu. Overall, this project helped me become more confident in Python programming.
